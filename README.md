# BCS360 – Smart Academic Growth System (SAGS)
A web-based academic learning portal designed for B.Sc. Computer Science students, aligned with the NEP 2024 curriculum of Savitribai Phule Pune University (SPPU).

## About the Project
BCS360 – Smart Academic Growth System is a student-oriented academic portal developed to make academic resources easily accessible.

The system organizes learning materials according to academic year, semester, and subject. It aims to provide students with a centralized platform for accessing theory resources and practical learning materials.

## Objectives

- Provide subject-wise academic resources.
- Organize content according to the NEP 2024 curriculum.
- Provide important exam-oriented questions.
- Offer online quizzes for self-assessment.
- Make textbook PDFs accessible.
- Develop an admin module to manage academic content.
